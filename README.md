# ToDo List

タスクを登録・管理するためのシンプルなToDoリストアプリです。

GitHubを使ったチーム開発の練習として、2人で役割を分担して制作しています。

## 主な機能

- タスクの追加
- タスクの完了状態の切り替え
- タスクの削除
- 完了したタスクの一括削除
- 残りのタスク数の表示

## 使用技術

- HTML
- CSS
- JavaScript
- Git / GitHub

## 開発の進め方

以下の流れで開発しています。

1. GitHub Issuesで作業内容を整理
2. 作業ごとにブランチを作成
3. 実装後にPull Requestを作成
4. コードを確認してmainブランチへマージ
